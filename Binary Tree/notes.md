🌳 Binary Tree — DSA Notes
1. What is a Binary Tree?

A Binary Tree is a tree data structure where each node can have at most two children:

Left Child
Right Child
        1
       / \
      2   3
     / \
    4   5
2. Basic Terminology
Term	Meaning
Root	Topmost node
Parent	Node having child nodes
Child	Node connected below a parent
Leaf	Node having no children
Edge	Connection between two nodes
Height	Longest path from node to leaf
Depth	Distance from root to a node
Subtree	Tree formed from a node and its descendants
